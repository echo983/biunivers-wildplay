# WildPlay V0.2 验收记录

状态：通过，归档

日期：2026-07-29

## 1. 自动校验

- `npm test`：5 个测试文件、20 项测试全部通过；
- `npm run lint`：TypeScript 严格检查通过；
- `npm run build`：生产构建与根目录静态包发布通过。

自动测试覆盖：

- EBML ID、VINT、元素边界、截断和安全整数；
- Matroska 文本与图形字幕轨识别；
- 超过 JavaScript 安全整数范围的 TrackUID 不影响字幕探测；
- Segment 时间尺度、Track 时间尺度和 Cue 位置；
- SimpleBlock、BlockGroup、BlockDuration 和轨道筛选；
- ASS 正文提取、样式标签移除和换行转换；
- Resource Session Range 与既有音视频播放回归。

## 2. 真实文件验收

样本：

- 文件大小约 1.47 GB；
- MKV；
- AVC 视频、AAC 音频；
- 10 条 ASS 文本字幕轨；
- 英语、葡萄牙语、西班牙语、阿拉伯语、法语、德语、意大利语、俄语和波兰语；
- 字幕索引包含 4044 个 Cue。

本地只读结构验证：

- 全部 10 条字幕轨被识别；
- Cue 时间和 Cluster 文件位置可解析；
- 可按 Range 从目标 Cluster 读取实际 ASS 正文；
- 未对视频执行完整下载或顺序扫描。

Biunivers 真实链路人工验收：

- 字幕轨可以选择；
- 字幕可以显示和关闭；
- 同名 Track 使用“名称 · 语言”区分；
- 选中标记和未选中项目对齐正常；
- Seek 后字幕快速恢复；
- 多次 Seek 不显示旧位置字幕；
- 音视频播放保持正常。

## 3. 已知边界

以下行为符合 V0.2 设计，不阻塞验收：

- 不显示 PGS、VobSub 等图形字幕；
- ASS/SSA 只保证正文、换行和基础可读性，不实现复杂排版特效；
- 不支持字幕 ContentEncoding；
- 文件完全没有可用 Cue 时，不以全文件扫描兜底；
- 暂不支持外挂字幕、字幕样式设置和音轨选择。

## 4. 结论

V0.2 的正常路径、选择路径、Seek 路径、关闭路径和局部失败路径均已闭环。代码、静态应用包
和文档具备合并条件。
