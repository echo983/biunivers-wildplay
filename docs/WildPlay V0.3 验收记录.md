## 人工验收

- 真实 MKV；
- 音轨菜单正常显示当前轨道；
- 不影响既有播放与字幕行为。

双音轨样本：

- 20 秒 MKV，640×360 H.264 黑色视频；
- `Japanese 440 Hz · jpn · AAC · 1ch`，默认轨；
- `English 660 Hz · eng · AAC · 1ch`；
- 文件约 655 KiB。

验收结果：

- 两条轨道的名称、语言、codec 和声道数显示正确；
- 默认轨正确；
- 440 Hz 与 660 Hz 可听辨并可往返切换；
- 播放中切换保持大致位置并继续播放；
- 暂停时切换保持暂停；
- Resource Session 保持有效。

测试文件位于用户本地视频目录，不属于应用源码或发布包，未提交到 Git。

## 已知边界

- 不做多音轨混音；
- 不做音频延迟、均衡器、声道映射和响度归一化；
- 不持久化跨文件语言偏好；
- 切换需要重新预缓冲，不承诺无缝切换；
- 不可由浏览器解码的轨道显示为禁用。

音轨枚举、选择、播放中切换、暂停切换、失败隔离和 Input 重建路径均已闭环。V0.3 具备
合并条件。
