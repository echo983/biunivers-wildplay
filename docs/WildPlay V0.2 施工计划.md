# WildPlay V0.2 施工计划

状态：全部完成，归档

日期：2026-07-29

## 阶段 1：解析基础

- 实现有边界检查的 EBML element header、VINT、整数和字符串读取；
- 用合成字节测试正常、截断、未知尺寸和溢出；
- 实现 Segment、SeekHead、Tracks、Cues 的结构解析；
- 只暴露受支持的文本字幕轨。

完成条件：可从合成和真实 MKV 中列出字幕轨与 Cluster 索引。

结果：完成。

## 阶段 2：字幕 cue

- 按播放位置选择 Cluster；
- 解析 SimpleBlock 与 BlockGroup；
- 处理 TimestampScale、BlockDuration 和缺省结束时间；
- 转换 UTF-8、ASS/SSA、WebVTT 文本；
- 增加时间窗缓存、generation 和读取上限。

完成条件：单轨字幕能随播放和 Seek 正确输出 cue。

结果：完成。真实样本包含 10 条 ASS 字幕轨和 4044 个 Cue。

## 阶段 3：界面

- 增加视频画面右键菜单；
- 增加“字幕 > 关闭/轨道”；
- 增加安全 DOM 字幕叠加层；
- 全屏、窗口和控制条显隐不遮坏字幕；
- 字幕错误显示为非致命状态。

完成条件：用户可切换、关闭字幕，音视频不受字幕失败影响。

结果：完成。字幕菜单使用“名称 · 语言”区分同名轨道。

## 阶段 4：验收与交付

- 运行 lint、单元测试和构建；
- 对无字幕媒体做回归；
- 对真实多字幕 MKV 测试播放、切轨和多次 Seek；
- 检查网络请求保持 Range 读取；
- 更新 README、版本与验收记录；
- 提交并推送功能分支，具备合并条件后再合并。

结果：完成。自动测试、类型检查、生产构建和真实 MKV 人工验收均通过。
